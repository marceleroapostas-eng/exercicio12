# Exercício 12 - Maior Número



## Descrição



Este programa solicita dois números inteiros ao usuário e verifica qual deles é o maior. Caso os dois números sejam iguais, o programa informa que eles possuem o mesmo valor.



## Tecnologias utilizadas



- Java

- NetBeans

- Maven



## Entrada



A entrada contém dois números inteiros informados pelo usuário.



## Saída



O programa apresenta qual dos dois números é o maior ou informa que os dois números são iguais.
